Resumo rapido

Se o usuario nao informar nenhuma flag de plataforma, o empacotamento segue o sistema operacional atual. Ou seja: Linux gera Linux, Windows gera Windows e macOS gera macOS.

Para abrir esta pagina pelo terminal do projeto, use grafic-cm doc.

Primeiros passos

A biblioteca depende de electron no projeto consumidor. Se voce quiser usar o comando de empacotamento, tambem precisa instalar electron-builder.

1. Instale a biblioteca
Terminaldependencias base
npm install grafic-cm electron
2. Instale o empacotador
Terminaldependencia de build
npm install -D electron-builder
3. Crie seu HTML

O campo app aponta para o arquivo HTML que sera aberto na janela principal.

Uso basico

Este e o fluxo mais comum: importar a funcao janela e passar as opcoes iniciais.

exemplo.jsESM
import grafic, { janela, electron } from 'grafic-cm';

janela({
  app_nome: 'Minha App',
  tela_cheia: true,
  menu_Padrao: false,
  altura: 600,
  largura: 800,
  app: './index.html',
  icone: './image.png'
});

const { ipcMain } = electron;
console.log('App iniciada com Grafic-CM');
Import default tambem funciona
exemplo.jsdefault export
import grafic from 'grafic-cm';

grafic.janela({
  app_nome: 'Minha App',
  app: './index.html',
  icone: './image.png'
});

API da funcao janela()

Estes sao os campos aceitos hoje pela biblioteca.

Opcao Tipo Padrao Descricao
tela_cheia boolean false Abre a janela em modo fullscreen.
menu_Padrao boolean true Se for false, remove o menu da janela.
altura number 600 Altura inicial da janela.
largura number 800 Largura inicial da janela.
app string demo interno Caminho para o HTML carregado pela janela.
app_nome string sem nome Nome da app e titulo da janela.
icone string sem icone Caminho para o icone da janela. Caminhos relativos sao resolvidos a partir de process.cwd().

Como funciona o icone

O campo icone ja facilita muito o uso, mas vale separar o comportamento em runtime e em build final.

Durante a execucao

O caminho informado em icone e usado como icone do BrowserWindow. No macOS, o pacote tambem tenta aplicar o icone no dock.

No executavel compilado

O icone do arquivo final, como .exe, .app ou pacote Linux, ainda depende da configuracao do electron-builder ou da ferramenta de empacotamento que voce usar.

CLI: grafic-cm empacotar

Ao instalar o pacote, o comando grafic-cm fica disponivel no terminal do projeto.

Abrir a documentacao
Terminalbrowser padrao
grafic-cm doc

Esse comando abre automaticamente a pagina HTML de documentacao no navegador padrao do sistema.

Comando padrao
Terminalplataforma atual
grafic-cm empacotar

Sem nenhuma flag, o build segue a plataforma em que o comando esta rodando.

Forcando a plataforma
Terminalalvos explicitos
grafic-cm empacotar --win
grafic-cm empacotar --linux
grafic-cm empacotar --mac
Passando mais argumentos
Terminalflags do electron-builder
grafic-cm empacotar --mac --publish never
grafic-cm empacotar --win portable

Regras por plataforma

O comportamento padrao e simples, mas empacotamento cross-platform no Electron tem limites praticos.

Sem flag de plataforma
  • No Linux, o comando tende a gerar build para Linux.
  • No Windows, o comando tende a gerar build para Windows.
  • No macOS, o comando tende a gerar build para macOS.
Limite importante

Gerar build para outro sistema pode exigir ferramentas extras. Exemplo: build de Windows em Linux pode depender de Wine. Build de macOS costuma exigir o proprio macOS para assinatura e empacotamento corretos.

Fluxo completo recomendado

Se voce quiser ir do zero ate o executavel, este e um fluxo seguro.

  1. Instale grafic-cm e electron.
  2. Instale electron-builder como dependencia de desenvolvimento.
  3. Crie o seu index.html e o ponto de entrada Electron.
  4. Abra a janela com janela({ app: './index.html' }).
  5. Configure o build do seu projeto Electron.
  6. Rode grafic-cm empacotar ou uma flag especifica como --win.

Perguntas frequentes

  • Preciso instalar o pacote globalmente? Nao. Se preferir, use npx grafic-cm empacotar.
  • Se eu nao passar app, o que acontece? A biblioteca carrega um HTML demo simples.
  • O comando grafic-cm empacotar empacota sozinho sem configuracao? Ele chama o electron-builder do projeto atual. O comportamento final depende da configuracao do app consumidor.
  • O icone do executavel final vem so do campo icone? Nao. Esse campo ajuda no runtime. O executavel final ainda depende da configuracao de build.
